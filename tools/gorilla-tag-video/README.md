# gorilla-tag-video

Замена персонажа в видео на гориллу Gorilla Tag со скина-референса
(фиолетовый худи, крылья, серая морда «monke»).

Утилита самостоятельная и никак не связана с модулями лаунчера —
лежит здесь просто как инструмент. Требует Python 3.11, `numpy`,
`opencv-python-headless`, `Pillow`, `imageio-ffmpeg`.

## Как это устроено

Никакой генеративной модели — обычный VFX-конвейер, поэтому результат
детерминированный и повторяемый.

| Файл | Что делает |
|---|---|
| `gorilla_asset.py` | Векторный рендер головы гориллы. Геометрия снята линейкой с референс-скрина (лицевая пластина 318×192 px, глаза 135×72 @ ±86, капюшон 402 px). Рисуется с 4× суперсэмплингом в 8-битные маски, цвет считается уже на выходном разрешении — чистая альфа на любом масштабе. Три режима: `full`, `silhouette`, `outline`. |
| `segs.py` | Разбиение ролика на монтажные планы. |
| `hints.py` | Якоря головы по одному на план, снятые вручную в масштабе 1:1. |
| `track.py` | Трекинг по шаблону (NCC, локально нормализованная яркость — устойчиво к цветокору), затем RANSAC-сглаживание траектории и линейная модель масштаба. Сглаживание и есть защита от дрожания. |
| `composite.py` | Посадка головы по габаритам, грейд под сцену (перенос статистик LAB области, которую голова накрывает), альфа-композитинг. |
| `hoodie.py` | Перекраска футболки в фиолетовый худи поворотом тона по цветовому ключу — светотень и края оригинала сохраняются, поэтому шва не возникает. Применяется только к проверенному списку планов. |
| `render.py` | Прогон всех кадров и сборка с оригинальной звуковой дорожкой. |

## Запуск

```bash
ffmpeg -i src.mp4 -vsync 0 -q:v 2 frames/f%04d.jpg   # разложить на кадры
python3 segs.py && python3 track.py && python3 render.py
```

## Границы применимости

Якоря в `hints.py` и подстройки `TWEAK` в `composite.py` привязаны
к конкретному ролику. Для другого видео их нужно снять заново —
всё остальное переносится без изменений.
